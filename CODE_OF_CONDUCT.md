# Code of Conduct

## Purpose

To maintain a sustainable and usable project, contributors are expected to adhere to a minimal set of standards and behavior practices.

## Expectations

- Be respectful and constructive in all communication
- Only introduce breaking changes after discussions
- All contributions must be through Pull Requests
- Clearly describe your changes in the Pull Request
- Respect the structure and standards of the project

## Contributor Workflow

1. Fork the repository
2. Create a new branch for your feature or fix
3. Make your changes
4. Open a Pull Request against the `main` branch
5. Provide a clear and descriptive title and description
6. Wait for review and approval

## Not Accepted

- Direct pushes to the `main` branch
- Changes without review and description
- Contributions that change licensing terms

## Good Practices

- Test changes locally before submission
- Use existing directory and naming conventions
- Update documentation when relevant
- Make atomic commits with clear descriptions

## Contact

For discussions or questions, open an [issue](https://github.com/zero-desktop/zero-desktop-lxde/issues).
